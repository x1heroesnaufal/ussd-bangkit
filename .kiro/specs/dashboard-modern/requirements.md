# Requirements — Panel MODERN

1. Panel di samping HP menampilkan: umpan pesanan terbaru (maks. 8, live), total transaksi sesi ini, dan saldo dompet saat ini.
2. Papan kurs uang digital: BTC, ETH, USDT dalam IDR, diperbarui berkala dari API publik; bila API gagal, tampilkan angka simulasi dengan label "simulasi" (jangan pernah menampilkan papan kosong/error).
3. Setiap pesanan sukses memicu animasi hantu maskot "Si Arwah" melintas di panel selama ±2 detik.
4. Panel bisa dilipat/dibentangkan dengan satu tombol agar kontras jadul-vs-modern terasa saat demo.
5. Panel memakai palet ungu Halloween + krem sesuai steering design; layar HP tidak terpengaruh panel.
